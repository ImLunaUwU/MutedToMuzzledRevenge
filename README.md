# MutedToMuzzled (Revenge)

![Preview](https://imluna.dev/images/Mutt.jpg)

Replaces Discord Android's muted mic icon with the muzzle from
https://github.com/zoez22/muzzlemute

This is a plugin, not a theme. Revenge themes cannot replace icons.

## Installing

Open your Revenge (Discord) settings, go to Plugins (Category: Revenge), click the <span style="font-size:1.5em">+</span> button in the bottom-right corner, and paste this URL:
https://lunauwu.net/MutedToMuzzledRevenge/

## Screenreader note

It is not known how screen readers will respond to this modification.
Unexpected behavior may occur.
